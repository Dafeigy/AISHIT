# 语音交互设计

## 1. 目标与当前范围

语音是鼠标、键盘之外的另一种输入通道。语音识别只负责把音频转换成文本；文本经过规则解析后形成结构化命令，再交给页面的业务动作执行。

第一版仅支持海浪模拟场景中的风机概览：

- 按编号打开某台风机的概览。
- 关闭当前打开的风机概览。
- 未匹配的语音仍按原有消息输入逻辑处理。

## 2. 设计原则

1. **输入与动作解耦**：语音不模拟 DOM 点击或 Three.js 射线点击，而是复用鼠标点击最终调用的业务动作。
2. **结构化命令稳定**：当前由规则解析器生成命令；未来接入 LLM function calling 时，只替换命令生成层。
3. **集中注册能力**：按资源类型注册动作，不给 55 台风机分别编写槽位。风机编号是命令参数。
4. **执行前校验**：资源编号、页面状态和参数均由执行器校验。
5. **只消费最终转写**：避免 ASR 中间结果导致同一命令重复执行。

## 3. 处理流程

```text
麦克风音频
  → ASR 最终文本
  → 文本标准化与规则匹配
  → VoiceInteractionCommand
  → OceanInteractionProvider
  → 选择风机 / 关闭 Dialog
  → 界面反馈
```

鼠标点击和语音命令最终都调用 `selectTurbine(turbine)`，保证行为一致。

## 4. 命令协议

### 4.1 打开风机概览

```json
{
  "name": "check_windturbine",
  "arguments": {
    "turbineNo": 12
  }
}
```

当前支持的表达包括：

- 查看 12 号风机
- 打开十二号风机
- 显示第 12 号风机概览
- 看一下二十三号风机详情

执行器根据 `turbineNo` 查询风场资产。编号不存在时不改变页面状态，并提示当前有效编号范围。

### 4.2 关闭概览

```json
{
  "name": "close_dialog",
  "arguments": {}
}
```

当前支持的表达包括：

- 关闭窗口
- 关掉概览
- 收起弹窗
- 关闭
- 关掉

只有当前存在打开的风机概览时才改变状态；否则返回已识别但无需执行的结果。

## 5. 模块职责

| 模块 | 职责 |
| --- | --- |
| `useRecorder` | 录音并取得 ASR 最终文本 |
| `voice-command.ts` | 文本标准化、规则匹配、生成结构化命令 |
| `wind-farm-assets.ts` | 风场资产共享数据与按编号查询 |
| `OceanInteractionProvider` | 校验和执行命令，维护当前风机及 Dialog 状态 |
| `MessageComposer` | 将最终转写交给命令入口，并展示执行反馈 |
| `OceanCanvas` | 鼠标选中风机后调用同一个 `selectTurbine` 动作 |

## 6. 匹配与冲突规则

- 标点和空格不影响匹配。
- 支持阿拉伯数字和一百以内常见中文数字写法。
- 打开命令必须同时包含查看类动作、编号和“风机”，避免普通聊天误触发。
- 单独说“关闭”“关掉”“收起”可关闭概览；带目标时支持“窗口、概览、弹窗、对话框、详情”。
- 一条最终转写只生成一个命令。第一版关闭命令优先于打开命令。
- 未匹配文本返回 `null`，继续原有消息发送或填入输入框的流程。

## 7. 扩展方式

后续可在命令联合类型和执行器中增加新的能力，例如：

```ts
type VoiceInteractionCommand =
  | { name: "check_windturbine"; arguments: { turbineNo: number } }
  | { name: "check_substation"; arguments: { substationId: string } }
  | { name: "toggle_layer"; arguments: { layer: string; visible: boolean } }
  | { name: "close_dialog"; arguments: Record<string, never> }
```

接入 LLM 后，应要求模型输出同一协议，并继续由本地执行器负责参数校验和状态变更。涉及启停设备、参数修改等高风险动作时，需要另加确认步骤，不能沿用查询概览的直接执行策略。

## 8. 第一版验收用例

| 输入 | 预期结果 |
| --- | --- |
| `查看1号风机` | 打开 1 号风机概览 |
| `打开十二号风机` | 打开 12 号风机概览 |
| `显示第55号风机详情` | 打开 55 号风机概览 |
| `查看56号风机` | 不打开窗口，提示编号范围 |
| `关闭窗口` | 关闭当前风机概览 |
| `关掉` | 关闭当前风机概览；未打开时提示无需操作 |
| `今天天气怎么样` | 不生成命令，进入原有消息流程 |
